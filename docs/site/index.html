Change tracking for TypeScript

Know what changed, and undo it.

Subclass ChangeSet, mark fields with @attr(), and every assignment is tracked. Ask the record whether it is dirty, read its changes as a hash, reset it, or build one record over many and see which fields they disagree on.

Get started API reference GitHub

Install

One file, no dependencies

change-set is experimental and not on npm. Copy change-set.ts into your project. It uses TypeScript's legacy decorators, so turn them on: 

{
  "compilerOptions": {
    "experimentalDecorators": true
  }
}

Usage

Track a record

Each @attr() field becomes an attribute that remembers the value it started with. Assigning to the field marks it dirty; reset() puts the starting value back. 

import {attr, ChangeSet} from './change-set';

export class User extends ChangeSet {
    @attr() name: string;
    @attr() age: number;
}

const user = new User({name: 'Joe', age: 25});
user.name = 'John'
user.name == 'John'; // true
user.attributeFor('name').dirty // true
user.reset()
user.attributeFor('name').dirty // false
user.name == 'Joe'; // true

Edit many records at once

fromArray builds one change set over several records and marks the attributes they disagree on as mixed, for a bulk-edit form. 

const user1 = new User({name: 'Joe', age: 25});
const user2 = new User({name: 'Joe 2', age: 25});
const user3 = User.fromArray([user1, user2])

user3.attributeFor('age').mixed // false
user3.attributeFor('name').mixed // true
